# mentor/client/

Клиентские gRPC-сервисы — API для фронтенда (Telegram Mini App / Web).

## Сервисы

| Директория | Сервис | Назначение |
|------------|--------|------------|
| `auth/` | `AuthService` | Аутентификация через Telegram (Mini App, Widget), управление сессиями |
| `identity/` | `IdentityService` | Профиль текущего пользователя, смена языка |
| `billing/` | `BillingService` | Покупка подписок, управление подписками, балансы, транзакции, квоты |
| `bot/` | `BotService` | CRUD ботов для авторов, тарифные планы, дашборд автора |
| `chat/` | `ChatService` | Диалоги с ботами, сообщения, контакты, реалтайм-стрим событий |
| `market/` | `MarketService` | Каталог ботов, поиск, избранное, библиотека пользователя |
| `memory/` | `MemoryService` | Память бота о пользователе (факты, настройки ключ-значение) |
| `call/` | `CallService` | Голосовые звонки через WebRTC/VAPI |
| `system/` | `SystemService` | Системная конфигурация, стрим курсов валют |

## Авторизация

Все методы (кроме `AuthService.Login`) требуют заголовок `Authorization: Bearer <session_token>`.
Контекст текущего пользователя извлекается из сессии на стороне сервера.
