# mentor/client/call/

## CallService

Сервис голосовых звонков через WebRTC/VAPI.

### RPC-методы

| Метод | Описание |
|-------|----------|
| `GetCallLink` | Получить ссылку для начала голосового звонка с ботом |

### Модели

- **`GetCallLinkRequest`** — `bot_id` + произвольные параметры (`map<string, string> params`)
- **`GetCallLinkResponse`** — сформированная ссылка + метаданные для настройки подключения

### Статус

Ожидает интеграции с VAPI (провайдер голосовых AI-звонков).
