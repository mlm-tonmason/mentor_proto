# mentor/client/market/

## MarketService

Сервис каталога и витрины ботов — поиск, избранное, библиотека.

### RPC-методы

| Метод | Описание |
|-------|----------|
| `GetBot` | Детальная информация о боте |
| `SearchBots` | Поиск и фильтрация ботов (жанр, теги, рейтинг, флаги) |
| `RateBot` | Оценить бота (1–5 звёзд) |
| `AddToFavorites` / `RemoveFromFavorites` | Управление избранным |
| `ListMyLibrary` | Библиотека: купленные + избранные + недавние боты |

### Фильтрация (`SearchBotsRequest`)

- **По жанру**: TWIN (двойники), EXPERT (эксперты)
- **По тегам**: Категории через строковые теги
- **По рейтингу**: Минимальный порог
- **По флагам**: `is_hot`, `is_favorite`, `is_subscribed`
- **По создателю**: `creator_id`
- **Текстовый поиск**: По системному имени (prefix)
