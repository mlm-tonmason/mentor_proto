# mentor/client/system/

## SystemService

Сервис системных данных и конфигурации.

### RPC-методы

| Метод | Описание |
|-------|----------|
| `GetConfig` | Получить справочники: локали, валюты, валютные пары, текущие курсы |
| `StreamExchangeRates` | Server-stream: обновления курсов валют в реальном времени |

### Особенности

- `GetConfig` возвращает полный `SystemConfig` — все справочники одним запросом при старте приложения.
- `StreamExchangeRates` — бесконечный стрим, сервер отправляет `ExchangeRate` при изменении любого курса.
