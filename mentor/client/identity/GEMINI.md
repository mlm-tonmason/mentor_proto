# mentor/client/identity/

## IdentityService

Сервис профиля и настроек текущего пользователя.

### RPC-методы

| Метод | Описание |
|-------|----------|
| `GetMyProfile` | Получить полный профиль текущего пользователя (с данными из Network) |
| `ChangeLanguage` | Сменить язык интерфейса (`ru`, `en`) |

### Особенности

- Профиль обогащается данными из внешнего Network Service (username, avatar, balances) в реальном времени.
- Локальные данные (язык) хранятся в БД Mentor.
