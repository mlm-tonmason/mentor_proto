# mentor/

Корневой пакет protobuf-определений проекта **Mentor** — платформы AI-ботов (экспертов и двойников) с подписочной моделью монетизации.

## Структура

```
mentor/
├── types/       — Общие доменные модели (сущности, enum-ы, типы данных)
├── client/      — Клиентские gRPC-сервисы (API для фронтенда)
└── admin/       — Административные gRPC-сервисы (API для управления платформой)
```

## Архитектура

- **types/** — переиспользуемые модели, импортируемые как клиентскими, так и админскими сервисами.
- **client/** — сервисы для конечных пользователей: аутентификация, чат, биллинг, маркетплейс, управление ботами.
- **admin/** — сервисы для администраторов: управление авторами, подписками, модерация ботов, профили пользователей.

## Стайл-гайд

- Все комментарии в `.proto` файлах — на русском языке.
- Enum-ы обёрнуты в message (`message Status { enum Id { ... } }`).
- Сущности содержат вложенные `message Id`, `message List`.
- Пагинация — через `Cursor` или `page_size/page_token`.
