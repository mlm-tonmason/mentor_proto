# mentor/admin/author/

## AuthorAdminService

Админ-сервис управления настройками авторов — лимиты на создание ботов.

### RPC-методы

| Метод | Описание |
|-------|----------|
| `SetAuthorBotLimit` | Установить лимит `max_bots` для автора |
| `GetAuthorBotLimit` | Получить текущий лимит и количество созданных ботов |

### Модели

- **`AuthorSettings`** — `author_id`, `max_bots`, `current_bot_count`

### Логика

- `max_bots = 0` — автору **запрещено** создавать ботов (по умолчанию у новых пользователей).
- Уменьшение лимита не удаляет существующих ботов — только запрещает создание новых.
- Доступ: только администратор (`admin_user_ids`).
