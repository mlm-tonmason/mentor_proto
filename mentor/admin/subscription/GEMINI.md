# mentor/admin/subscription/

## SubscriptionAdminService

Админ-сервис управления подписками — подарочные подписки, продление, отмена.

### RPC-методы

| Метод | Описание |
|-------|----------|
| `GrantSubscription` | Подарить подписку без оплаты (промо, тестирование, компенсация) |
| `ExtendSubscription` | Продлить существующую подписку на дополнительный период |
| `CancelSubscription` | Принудительно отменить подписку |
| `GetSubscription` | Детальная информация о подписке (подписка + план + подписчик + автор) |
| `ListUserSubscriptions` | Все подписки конкретного пользователя |

### Особенности

- `GrantSubscription` создаёт подписку сразу в статусе `ACTIVE` + транзакцию с `amount = 0`.
- `ExtendSubscription` работает только с `ACTIVE` подписками.
- `reason` — записывается в аудит-лог (`tracing::info!`), не хранится в БД.
- Все методы — только для администратора.
